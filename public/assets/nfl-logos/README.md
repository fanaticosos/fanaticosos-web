# NFL team logos

This directory contains the 32 team marks used by the FanaticOSOS Game Center so that page rendering does not depend on a third-party image request.

- Source: ESPN team-logo CDN (`https://a.espncdn.com/i/teamlogos/nfl/500/{team}.png`)
- Retrieved: 2026-09-10
- Format: PNG, normalized to fit within 256 × 256 pixels
